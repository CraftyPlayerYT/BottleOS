## 📖 What is BottleOS?

BottleOS is a free, open-source operating system built from the ground up by a global community of developers. It is designed to be modular, lightweight, and accessible to everyone — from students discovering their first terminal to enterprises running large-scale infrastructure.

Unlike proprietary systems, BottleOS belongs to its community. Every line of code is transparent, auditable, and improvable by anyone who wishes to contribute.

---

## 🎯 Philosophy

- **Openness** — The source code is fully public and licensed under the GPL v3.
- **Community-first** — Every decision is made with contributors and users in mind.
- **Modularity** — BottleOS is designed to be lightweight at its core, with optional layers built on top.
- **Accessibility** — Whether you are a student or a Fortune 500 company, BottleOS has an edition for you.
- **Charity** — Revenue generated by the Enterprise edition is entirely donated to charities.

---

## 🧩 Editions

BottleOS comes in four editions, each tailored to a specific audience:

| Edition | Target audience | Price |
|---|---|---|
| 🎓 **BottleOS Student** | Students and learners | **Free** |
| 👤 **BottleOS Individual** | Personal and home use | **Free** |
| 🤖 **BottleOS AI** | AI developers and researchers | **Free** |
| 🏢 **BottleOS Enterprise** | Businesses and organizations | **Paid** 💝 |

> 💝 **100% of Enterprise revenue is donated to charities.** BottleOS is a project driven by passion, not profit.

## 🤝 Contributing

BottleOS is community-driven and welcomes contributions from developers of all skill levels.

Whether you want to fix a bug, improve documentation, suggest a feature, or write new modules — your help is valuable and appreciated.

### Before contributing, you must:

1. Read the **[Rules.md](Rules.md)** file carefully.
2. By submitting any contribution (pull request, issue, patch, or otherwise), **you automatically agree to and accept all rules defined in Rules.md**. No exceptions.
3. Make sure your code follows the coding standards described in Rules.md.

> ⚠️ Any contribution that does not comply with the rules defined in Rules.md will be rejected without further notice.
